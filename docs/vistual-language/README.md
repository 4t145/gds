# GDS 视觉语言 · 通用基线与原生修订

本文沿用 0.3 概念基线并纳入原生实现修订，适用于整个 GDS 应用套件。与历史 HTML / PNG 不一致时，以这里的入口、NavItem、材质和即时设置规则为准；图片不代表原生验收结果。目录名沿用项目约定的 `vistual-language`。

## 1. 设计原则

**同一语义，同一外观，同一交互；桌面主题改变颜色，不改变用户已经学会的语言。**

- 原生、安静、紧凑。以内容为主，不做大面积宣传式留白、卡片堆叠或装饰性渐变。
- 常用动作优先使用图标；悬停和键盘聚焦时，以统一 tooltip 显示短动作名与独立键帽。图标按钮仍须有短可访问名称；无绑定动作不虚构快捷键，详见 [快捷键与键帽](shortcuts.md)。
- 文件名、位置、错误等用户需要辨认的内容保留文字，不把“少说明”误解成“全部图标化”。
- 颜色、字体、密度、材质由套件级设置控制；各应用不能另建一套主题和图标解释。
- 公共组件先承载交互，再接受语义主题。不要让每个应用复制一份组件样式。

## 2. 三层契约

| 层次 | 统一内容 | 允许变化的内容 |
| --- | --- | --- |
| 语义 | 动作名、图标、危险等级、焦点、选中与禁用的含义 | 应用提供的动作集合和对象能力 |
| 组件 | 工具栏、侧栏、纵向标签、面包屑、菜单、对话框、通知、任务进度 | 内容、尺寸约束、合理的布局组合 |
| 主题 | 语义颜色、字体、密度、表面透明度、动效偏好 | Qt／DMS／内置主题的取值 |

应用只能请求 `surface.sidebar`、`text.secondary`、`action.destructive` 等语义角色，不使用“文件浏览器绿”“应用 A 灰”等私有主题键。来源识别与映射详见 [共享主题](theme.md)。

## 3. 形状、节奏与排版

以下是首版建议值，不是散落到各应用中的常量；实现时集中为公共 token。

| 项目 | 常规密度 | 紧凑密度 / 说明 |
| --- | --- | --- |
| 间距 | 4、8、12、16、24 px | 4 px 基准，避免随意添加近似尺寸 |
| 主要文字 | 14 px | 跟随系统字体与缩放；不是锁定物理像素 |
| 次级文字 | 12–13 px | 仅用于路径、元数据、辅助状态 |
| 图标 | 16 / 20 px | 约 1.75 px 线宽，同套图标不混用填充与描边风格 |
| 常规交互高度 | 36 px | 紧凑 30–32 px；图标实际点击区不小于 28 px |
| 侧栏 NavItem | 38 px 点击区 / 18 px 图标 | 展开左对齐、折叠居中；侧栏内边距统一 10 px |
| 底部区域 | 36 px | 左列同材质留白，不画分割顶线；右侧显示状态 |
| 文件数据表 | Kit DataTable | 表头和数据行共用列宽模型，使用虚拟滚动 |
| 组件圆角 | 6 px | 分组表面 8 px；窗口轮廓遵循平台能力 |
| 分隔线 | 1 px | 低对比，不给每个区域套一层边框 |
| 动效 | 100–160 ms | 只表达状态变化；尊重减少动效设置 |

路径、文件名使用正常 UI 字体；只有终端和确实需要对齐的技术内容使用等宽字体。日期、大小等列使用可对齐数字。长文件名可以省略，但完整名称必须能通过提示或重命名框取得。

## 4. 状态不是一套换色游戏

| 状态 | 固定表达 | 避免 |
| --- | --- | --- |
| 悬停 | 轻微表面提亮 / 压暗 | 与选中同等强度 |
| 当前标签 / 当前位置 | 柔和强调底色 + 窄指示条 | 只靠文字变色 |
| 选中文件 / 条目 | 选中底色 + 对应前景色 | 把当前标签、焦点、文件选择合并为一个状态 |
| 键盘焦点 | 清晰焦点轮廓，可与选中叠加 | 因已有选中色而隐藏焦点 |
| 禁用 | 降低强调度，不可触发；必要时解释原因 | 低对比到无法辨认 |
| 进行中 | 进度 / 旋转状态符号 | 只改为黄色 |
| 错误 | 错误图标 + 短原因 + 可行动入口 | 只有红色边框或空白列表 |
| 危险操作 | 菜单中的明确动词；确认界面使用危险色 | 所有删除图标常驻鲜红 |

选中前景不假定为白色：浅色强调背景通常需要深色文字。普通文字目标对比度至少 4.5:1，关键非文本控件目标至少 3:1；半透明表面要在明暗壁纸上检查。高对比模式使用不透明表面，不能仅靠模糊保障可读性。

## 5. 固定图标词汇

操作图标使用一套套件级描边图标与语义注册表。具体资源优先复用 GPUI Kit 的图标能力；应用引用语义名，不直接指定某个 SVG 文件。以下词义不随应用改变：

| 语义名（概念） | 图形约定 | 使用方式 |
| --- | --- | --- |
| `app.menu` | 菜单图标 | 主页面全宽顶栏最左侧第一个控件，只包含设置与关于两个入口，不用应用品牌图标代替 |
| `navigate.return_to_files` | ArrowLeft | 设置中心在左上返回工作区，不使用右上 X；位置条目是固定特殊页签，不提供这种临时返回入口 |
| `navigate.back` / `forward` | 左 / 右箭头 | 历史后退 / 前进，不用于折叠面板 |
| `navigate.parent` | 向上箭头 | 上一级容器，不表示上传 |
| `panel.sidebar` | 带侧栏的矩形 | 展开 / 折叠侧栏；状态反映当前布局 |
| `panel.details` | 圆圈内信息图标 | 打开 / 收起右侧详情面板；文件内容标题栏中的按钮是唯一开关，面板标题栏沿用同一图标与名称，不重复关闭按钮 |
| `tab.new` | 加号 | 新建同类上下文，提示必须说明“新建标签页” |
| `tab.close` | 叉号 | 关闭上下文，不删除其内容 |
| `dialog.confirm` / `dialog.cancel` | 对勾 / 叉号 | 对话框主操作与取消；取消只放弃本次决定，不删除内容 |
| `file.copy` / `cut` / `paste` | 双页 / 剪刀 / 剪贴板 | 系统剪贴板语义 |
| `file.rename` | 文字编辑光标 | 重命名，而不是修改文件内容 |
| `file.trash` | 回收站 | 可恢复删除；永久删除使用明确文字区分 |
| `file.restore` | 回转箭头（Undo2） | 从回收站恢复到原位置，不表示撤销上一步编辑 |
| `terminal.open` | 命令提示符 `>_` | 打开终端；窗口级的显示 / 收起开关固定在底栏右下角，顶栏不重复放置 |
| `terminal.goto_current_folder` | 文件夹与方向箭头 | 显式跳转到当前文件夹，不表示自动目录同步或新建会话 |
| `search` / `settings` / `more` | 放大镜 / 齿轮 / 省略号 | 搜索 / 完整设置中心 / 次要动作 |
| `location.network` | 网络节点或服务器 | 网络位置，不借用同步图标 |
| `location.favorite` | 星形 | 收藏位置 / 书签，不表示固定标签 |
| `location.recent` | 时钟 | 最近打开记录，不表示当前标签的前进 / 后退历史 |
| `tab.pin` | 图钉 | 固定标签并排在前面，不表示收藏或窗口总在最前；固定后保留原图标，只在图标角上加小图钉角标，不把文件夹整体换成图钉 |
| `table.columns` | 带齿轮的列图标 | 打开表格列配置；调整显示与顺序，不表示筛选或排序 |

**操作图标与内容图标分开：**工具栏和菜单保持 GDS 词汇；文件类型、目录、已安装应用等内容图标可读取 freedesktop 图标主题，按继承链与 `hicolor` 回退，最后使用内置 MIME 图标。缩略图不是动作图标。切换系统图标主题不能把“删除”换成含义不明的图案。

**固定标记不替换图标：**标签、位置等“已固定”状态保留原图标，只在图标右下角叠加小图钉角标；图标保持 18 px 侧栏图标尺寸，行内对齐和标签文字位置不因固定与否而改变。公共 `pinned_icon` 提供这一种画法，各页不各写一份“固定就换成大图钉”的图标。

图标不足以区分多个同类标签时，展开态显示名称，折叠态以序号 / 短标记辅助，悬停提供完整名称和路径，不能展示一排无法区分的文件夹。

## 6. 公共组件与行为

- **应用框架：**全宽顶栏、可折叠侧栏与内容区、可选全宽底部停靠面板、统一底栏。各应用按需要组合，不强制每个应用都有侧栏或终端。窗口级开关（如终端）固定在统一底栏右侧，不在顶栏保留第二份开关。主窗口以明确的最小尺寸打开（Files 为 1000 × 640，初始 1280 × 820）：低于这个尺寸顶栏控件与右侧详情会互相挤压，因此不为更窄的宽度继续拆分响应式布局，窗口缩放与平铺仍交给窗口管理器。
- **纵向标签：**活动态、关闭、排序、溢出滚动、上下文菜单与折叠态一致；文件标签与终端页签共用视觉规则，但各自管理上下文。关闭按钮平时隐藏，本行悬停或按住 `Ctrl` 时显示；两种条件都消失时隐藏。展开和收起共用这条规则，收起时按钮位于右上角且尺寸更小，悬停提供名称与完整路径；显示或隐藏不让标签行、标题列宽与滚动位置跳动，隐藏状态也没有可点击的关闭区域。显示时每个标签都有自己的 X，点击只关闭对应标签；只有活动标签的关闭按钮显示 `Ctrl+W`（按住 Ctrl 时为 `W`），非活动标签不借用这个快捷键目标。按住 `Ctrl` 时，真正会被切到的相邻标签行显示 `Shift+Tab` / `Tab`，与 `Ctrl+Shift+Tab` / `Ctrl+Tab` 的目标一致；两个标签时两个方向落在同一行，两个标签并排而不是互相覆盖；只与自绘行尾的关闭角标保持距离，不压住 `W`。上下文菜单的关闭入口保持。
- **位置栏：**分段导航与文本编辑是同一组件的两种模式；编辑失败不破坏当前视图。路径按真实层级拆成独立块，父级块保留尾随分隔符，例如 `/mnt/st2000/assets` 显示为 `/` `mnt/` `st2000/` `assets`；父级块可点击，最后一块代表当前位置，`Ctrl+L` 仍进入文本编辑。
- **菜单：**打开类 → 编辑类 → 组织类 → 危险类 → 属性。分组按语义，不堆满所有可能动作；功能由目标对象能力决定。顶栏主菜单只保留“设置”和“关于”：设置复用工作区命令的同一条派发路径，右列显示真实 `Ctrl+,` 键帽；关于没有对应动作，因此不虚构快捷键。新建 / 关闭标签、终端等已在别处常驻的入口不重复放进主菜单。“关于”沿用共享确认对话框的视觉，显示应用名、`CARGO_PKG_VERSION` 和一句描述，关闭入口唯一；不罗列作者、网址或许可证等未确认的信息，也不新增页面框架。
- **对话框：**确认与取消使用公共 `DialogActions` footer：取消在左、主操作在右，均带图标与短文案；主操作默认强调色，危险确认换成危险色，取消保持普通款。按钮悬停提示显示同一组键帽（`Alt+A` / `Alt+C`），键盘仍保留 `Enter` / `Esc`。footer 只负责显示与派发，校验、取消回调与关闭顺序仍由对话框自身处理。
- **危险按钮状态：**主题层从来源危险色统一生成普通、悬停、按下三个可辨识状态，保持配对前景色；各个删除确认不单独硬编码颜色。交互反馈不改变按钮尺寸，禁用态不显示可执行的悬停 / 按下效果。
- **任务与反馈：**操作进度、结果及错误 / 警告使用共享气泡，不往文件列表或设置页中插入消息条；普通目录加载状态放在底栏。需要确认的危险操作仍使用对话框，输入字段校验保留在字段附近。
- **侧栏导航：**所有分类 / 位置条目使用公共 NavItem，统一点击区、图标尺寸和展开 / 折叠对齐方式，不由各页拼不同按钮。
- **数据表：**文件列表使用 Kit DataTable，共享表头与数据行的列定义和宽度，不分别手写两套 flex 列；虚拟滚动保留大目录交互能力。表格占满文件内容视口，水平滚动条固定在视口底部，不因只有一行数据而紧贴该行下方；行下方空白仍用于右键菜单、清除选择与拖放，但不覆盖滚动条。
- **设置：**主页面菜单或 `Ctrl+,` 打开完整设置中心，而不是外观抽屉或快捷键专用页；没有底部设置按钮。修改立即应用并自动保存，无 Save 条；应用 / 保存错误使用共享右上角气泡，不插入设置页内容。页面导航、错误语义和代码组织集中见 [设置中心](../settings/README.md)。
- **快捷键与提示：**全套件相似动作共享默认绑定；按键分发、按钮 tooltip、菜单右列及设置绑定列消费同一动作 / 有效绑定 / scope。各处共用 ShortcutBadge，不手写不同的快捷键字符串；默认表、键帽尺寸、对齐与焦点规则只在 [快捷键与键帽](shortcuts.md) 中维护。按住 `Ctrl` 或 `Alt` 时，当前可用控件浮出省略该修饰键的紧凑标签（`R`、`Shift+Tab`、`A`），松开即消失，规则见 [按住修饰键的功能提示](shortcuts.md#按住修饰键的功能提示)。

### 数据列表的视觉层次

数据列表沿用内容区的单次材质，不另铺实心表头或逐行横线。共享 `DataListStyle` 规定 40 px 行高、30 px 表头、6 px 行圆角；名称 13 px，时间 / 类型 / 大小 12 px 并使用次级前景，表头 11 px。仅保留表头下的一条轻分隔线。

悬停使用前景色的轻透明底色，不做亮白整条；选中用来源提供的强调背景与配对前景，内侧留少量垂直空隙。圆角和底色只作用于表面，不改变文字透明度或虚拟列表测量高度。长名称单行省略，图标不被挤压，悬停可看完整名称。实际色相和用户设置的不透明度继续由主题提供，不硬套概念图的绿色。

文件选择只以应用的原始路径集合为依据；右键目标在构造菜单后即清除组件暂存态，不另画持续外框。键盘位置保留为行为数据，不叠加第二个整行框；组件内部单行 / 列 / 单元格选择不得成为 Files 的第二套选择状态。文件、卷、回收站、最近与收藏统一使用公共 `ListSurface` 识别列表空白：左键或右键按下时取消当前页选择，同时清除键盘光标和范围起点；条目、表头和滚动条保留自身交互。空白范围按当前滚动位置判断，不在滚动后覆盖条目；文件框选仍先记录原选择，再处理空白按下。所有表头统一左对齐，大小列仅数据单元格右对齐。选中配色和选中层透明度暂按原值保留，背景透明度与选中层的叠加方式另行讨论。

隐藏文件的内容降低透明度，待剪切项进一步淡化并在名称旁显示剪刀标记；二者不叠乘到不可读，选中底色仍保持清晰。剪切标记来自剪贴板意图缓存，不在渲染时读取剪贴板。正常链接显示目标类别图标并加链接角标；断链使用断开的链接图标，无法访问目标不冒充断链。复制、剪切、粘贴菜单使用 Copy、Scissors、ClipboardPaste 图标。

文件与列拖拽的浮标贴近鼠标右下方，带文件类别图标或列手柄标记；不沿用源行的起点作为浮标位置。粘贴同名只提供改名或取消，不展示覆盖 / 合并动作；输入期仅验证名称形状，目标探测与文件操作在后台进行。背景目录与单选文件夹菜单提供“新建文件夹”，目标在发起时冻结。

### 列配置

文件内容标题栏右侧使用 `table.columns` 图标（或 `Alt+V`）打开列配置对话框；图标按钮遵循公共 IconButton 尺寸、悬停提示与焦点轮廓。对话框是草稿：勾选控制显示，拖住行首手柄可把该列放到目标行之前或列表末尾，目标行以细强调线反馈；行尾紧凑的上移 / 下移按钮与拖拽等价，保证键盘可操作。名称列不可隐藏，但可以重排；隐藏的列放在单独的弱化分组中，勾选后追加到可见列末尾。标题行只显示冻结的目标文件夹名（悬停可看完整路径）与应用范围，不再放大段说明；窗口过矮时滚动对话框内容，“应用”和“取消”始终可达。列拖拽使用对话框自己的载荷，不与文件拖拽混用。“应用”提交，“取消”或 `Esc` 丢弃草稿；取消一次拖拽只结束该拖拽，不关闭编辑器也不还原已调整的顺序。

- 作用域每次打开都默认“当前文件夹”，只影响该精确目录，不继承给子目录；用户显式选择“本应用默认”才修改本应用的默认列布局，不影响其它应用。保存成功后移除当前文件夹的专属覆盖，使其继承本应用默认值；其它文件夹的覆盖保持不变。保存失败时不移除现有覆盖。
- 有专属覆盖的文件夹可恢复使用本应用默认列，只删除该文件夹的覆盖，不修改应用默认值或其它文件夹。
- 列名与枚举使用公共下拉和 Fluent 文案；缺失的所有者、组、权限、访问时间显示“—”，当前用户作为所有者时以“名称（您）”加粗强调，但字号不变。权限使用 `rwx` 符号，悬停可查看八进制值；类型使用本地化大类或“到…的链接”，失效链接与无法访问的链接分别表述。选中行沿用配对前景色，不因加粗或次级文字降低对比度。
- 只持久化显示与顺序；列宽不写入配置，但在当前会话内按列身份记忆，隐藏或重排不会把宽度串给别的列。隐藏正在排序的列时回退到名称排序，表头不保留指向隐藏列的箭头。

### 回收站

回收站是与最近、收藏同级的虚拟位置，不是普通文件夹，也不拿“打开原路径”冒充浏览。内容区沿用同一数据表：名称（含类型图标）、原位置、删除时间、大小或目录项数；原位置列只作展示，不可点击导航。加载、真实空状态和读取失败各有明确状态，失败状态提供重试，底部状态栏显示记录数与选中数。恢复、永久删除、刷新与清空放在内容标题栏，右键菜单提供同一组动作；不在每一行常驻动作按钮。

- 选择按回收站记录的 id 维护，普通单选、`Ctrl` / `Shift` 多选与 `↑` `↓` `Home` `End` 可用；同一原位置的多条记录是独立行，不合并，也不作为当前文件路径参与复制、剪切、粘贴、拖拽或重命名。
- 永久删除与清空使用危险色确认对话框，确认前冻结记录集合；对话框出现后新进入回收站的项目不属于本次请求，取消不改变任何记录。删除键在回收站中同样进入这个确认，不直接执行。
- 恢复失败（如原位置已有同名项目）保留在回收站，批量结果用统一通知逐项说明；部分成功时重新读取列表。恢复会改变原目录，相关普通文件视图随之刷新，正在导航的旧结果不覆盖新结果。
- 恢复使用 `file.restore`，永久删除沿用 `file.trash`；清空使用扫帚（`Broom`）图标，标题栏只显示图标，悬停提示“清空回收站”，菜单仍保留动词标签。清空入口始终先打开确认对话框，确认按钮保留图标和文字，不用纯图标代替危险操作说明；确认界面才使用危险色，常驻图标不保持鲜红。

### 存储容量条

已挂载卷使用公共 `gds::ui::capacity::CapacityBar`，复用 Kit 的细条组件：填充部分表示已占用或保留的空间，剩余轨道表示当前用户可用空间。文字沿用次级字号，显示“剩余 / 总共”；侧栏和设备管理页使用相同组件，窄轨只显示小容量条，完整数值留在悬浮提示中。颜色跟随主题，不把只读介质的满容量一律渲染成错误。

卷条目的名称与下方容量内容共享一个完整的点击、悬停和选中区域，由公共 `NavItem` 的详情区域承载。侧栏卷条目作为独立固定页签打开默认挂载点，不增加普通页签；从卷页打开其他目录时新建普通页签，卷页保留默认挂载点。管理页使用与文件列表一致的 Kit DataTable，每卷一行，展示格式、空间和可选的默认挂载点；系统卷标记附在名称旁，容量条与文字整体垂直居中，单元格提供对称的上下留白。单击选中，双击或回车进入目录，方向键只移动选择；选中行沿用文件行的选中底色和文字颜色。右上角挂载／卸载动作作用于选中卷，复用 `IconButton` 的禁用、tooltip 快捷键和按住 Ctrl 显示的 hint；侧栏右键、管理页右键和行尾菜单保留相同动作和快捷键标记；卷目录页沿用文件页标题栏，不额外增加卷菜单按钮。设备层入口留给后续次要页面。

读取中显示不定进度与短状态，失败显示中性轨道和“容量暂不可用”，均不冒充真实的零用量。后台刷新时保留上一份有效数值；卸载或断开后移除容量条。

### 时间显示

所有时间值由公共 `gds::time::Timestamp` 呈现，传入原始 `SystemTime`，不由各表格自行拼时间字符串。组件继承文字颜色和字号，悬停显示带秒及 UTC 偏移的完整本地时间；未知值为“—”，不能冒充 UNIX 零时。

- 文件管理器默认使用相对格式：不足一分钟为“刚刚”，1–29 分钟为“几分钟前”；达到半小时后，同一本地日期显示“今天 HH:mm”、前一日显示“昨天 HH:mm”，更早使用天、周、日历整月和整年。相对模式下的零时间戳显示“UNIX 零时”；未来时间回退完整日期，避免负数“以前”。
- 完整格式为本地 `YYYY-MM-DD HH:mm`，包括零时间戳对应的真实日期。切换格式不改变文件时间、排序值或筛选结果。
- “设置 → 常规 → 时间显示”在相对时间和完整日期时间之间切换，当前属于本应用偏好；列显隐与顺序的文件夹覆盖不覆盖时间格式，也不向其它应用同步。
- 全应用共用一份低频时钟，按分钟刷新相对文本，不给每个单元格创建定时器；新数据渲染时使用当前时间，绝对格式不因时钟而重绘。

### 右侧详情

详情栏属于内容区，不另建一套卡片视觉：标题栏使用公共小标题与 `panel.details` 图标，面板以一条低对比分隔线与文件列表分开，宽度固定但列表列宽保留 `min_w_0` / `flex_1`，不能把内容列挤出窗口。打开 / 收起详情只通过文件内容标题栏中的同一个 Info 按钮（或 `Ctrl+P`）；面板标题栏保留图标与名称，但不再提供重复的关闭按钮。

- 只有单选时显示项目缩略图与元数据；空选显示“选择一个项目”，多选显示数量状态，不伪造第一个选中项。占位图标与文字在可用区域内水平和垂直居中，内容超出时由面板边界裁切或在内部滚动，不溢出到列表。
- 缩略图在后台读取。仅当有图像、正在加载、超出大小限制或受支持格式读取 / 解码失败时占用媒体区域，并各有稳定状态；没有可用预览的文件（如目录、未知格式）不画媒体框，也不同时留下大图标和说明文字，直接显示名称与元数据。解码格式按文件内容识别，不信任可能错误的后缀。
- 元数据沿用文件列表的格式与语义色，按类型补充可从文件头取得的图像尺寸、音视频参数、文本编码等信息。新增探测最多读取 256 KiB 前缀，不为页数、全文件行数或递归大小扫描文件；图片缩略图沿用独立的 32 MiB 限额解码，已读字节可复用。
- **详情底部不再显示当前文件地址，也不另建替代地址栏。** 路径导航由顶部位置栏负责；符号链接的“目标”是独立元信息，可以保留。
- 切换标签、目录或选择后，旧预览结果不得覆盖新状态。

### 通知气泡与共享接口

所有应用通过公共 `gds::notifications` 接口显示操作反馈，组件和后台结果无需持有 Files 的 `Browser` 引用。接口使用套件共享的 Kit 通知队列并在应用根视图平铺渲染，延后提交以避免重入窗口更新；队列、生命周期、关闭与同槽替换仍由 Kit 持有，不自建独立通知框架。

- 气泡位于顶部工具栏下方 **8 px**、窗口右侧 **12 px**；使用主题 popover 材质与配对前景，不参与文件列表、详情栏或设置页的布局。覆盖层只占内容高度，消息清空后不留下可点击的空白区域。
- 多条消息始终纵向完全展开，互不重叠，不依赖悬停才让出下层；错误和之后的临时成功提示可以同时读到。消息数量多于窗口高度时整列在窗口内滚动，不超出窗口。
- 错误保持到用户关闭；信息、成功和警告沿用 Kit 的自动消退。进度与最终结果复用同一通知槽，避免堆叠；目录读取警告只在结果应用时报告，不在 render 中重复生成。
- 摘要和明细在有界内容区域内滚动，长错误不超出窗口；关闭按钮留在滚动区域外。单次批量失败先列出最多四项并显示其余数量。
- 简单调用使用 `notifications::error(message, cx)` / `warning` / `info` / `success`；带明细使用 `Report`，异步操作的进度与结果使用 `Operation`。对话框内的输入校验与危险操作确认仍留在原本的交互位置。

### 公共设置值的视觉语言

枚举值使用下拉框（语言列表可搜索），数值使用带数值显示的滑块；不按当前选项数量临时拼按钮。偏离 GDS 默认值时，在控件左侧显示恢复默认图标按钮，未偏离时留出同宽空位。默认基线来自配置模型，不是最近保存值或系统当前配色。每项恢复独立生效，具体规则见 [设置中心](../settings/README.md#公共设置控件与默认值)。

### 共享网格与对齐契约

一个窗口使用一个公共网格，避免侧栏、终端和底栏分别拼布局：

- 公共列宽为 `--sidebar-width`：展开约 222 px，折叠 58 px。文件标签区与终端左侧竖向页签采用同一列宽和分界；折叠一次，两者同步变窄。分隔线由公共 Frame 在同一边界坐标覆盖绘制，顶栏、文件区与底栏共用同一条竖线，不用各区域 border 改变内部盒尺寸，以免交点出现一像素错位。
- 顶栏横跨整个窗口，位于所有侧栏上方。普通文件页和 Home / 最近 / 收藏 / 网络 / 回收站特殊页签的最左均为应用菜单；只有设置中心在同一位置改为 ArrowLeft 返回工作区，不使用右上 X。顶栏不显示 Files 文字或文件夹品牌标识。导航区只放后退 / 前进 / 上级与位置栏，终端等窗口级开关不放顶栏。
- 侧栏折叠按钮是顶栏中对齐列分界右侧的第一个控件。折叠按钮左侧从菜单按钮右缘到列分界的空白是窗口拖动热区：它是不含任何控件的独立空元素，按下即调用平台原生窗口移动，Wayland / Niri 由合成器接管，因此拖这段空白移动窗口，点菜单按钮和右侧控件仍只执行它们自己的点击。折叠后这里只剩不足 8 px 时不提供拖动热区，不留几乎无法命中的隐形区域；也不为拖动附加双击最大化等额外窗口行为。
- 文件区位于顶栏下方，左侧标签与位置、右侧内容。当前位置范围的槽位保留在全窗口底栏的侧栏列中，但暂时隐藏“本地”文字；终端展开或侧栏折叠均不额外显示替代标签，也不新增独立入口。终端 dock 位于文件区下方并横跨两列，左侧为竖向终端页签，右侧为会话视图；终端头部横线贯穿两列。
- 终端隐藏 / 最大化作用于整个 dock，包括左页签、头部和会话内容，不能只改变右侧视图。隐藏不结束任何会话。
- 整条左列（顶栏左区、文件或设置侧栏、终端左区、底部留白）各区域仅绘制一次相同侧栏背景；根保持透明，不能在左列下面叠内容底色。右侧内容区独立绘制背景。
- 最底部保留 **36 px** 对齐区域：左侧延续侧栏材质并保留空的位置范围槽，当前不显示“本地”，没有设置入口，也不画分割顶线；右侧先显示文件状态，最右是窗口级的终端显示 / 收起按钮。公共 Frame 为这三个区域提供独立内容槽。设置自身不再新增全宽保存底栏，不能用独立偏移拼接边界。

工具栏顺序和菜单命名保持稳定。键盘目标由当前焦点与动作 scope 决定，不由鼠标悬停决定；终端文本与终端页签栏是不同上下文。显式窗口级动作、输入保护及 tooltip 的目标匹配遵循 [快捷键焦点契约](shortcuts.md#4-焦点与-scope-契约)，不在各应用重写一份例外规则。

## 7. 材质规则

半透明是表面的属性，不是整个窗口的透明度。文字和图标保持不透明。

- 主内容与侧栏材质的不透明度分开配置；顶栏左区、侧栏、终端左区与底部留白使用同一侧栏材质，不因切到设置页而叠加内容背景。原生当前可配置项与后续终端能力见 [运行说明](../development.md)。
- 菜单、提示、冲突对话框默认不透明；不为了“玻璃感”牺牲文字可读性。
- 模糊单独设置为关闭 / 自动。`自动` 表示在窗口系统与合成器支持时请求，不承诺所有 Linux 桌面都能实现。
- 关闭所有效果后，视觉层级仍由颜色、间距、分隔线和焦点表达成立。
- 概念原型中的壁纸与透明效果只是材质示意，不代表 GPUI 已获得桌面背板模糊能力。

## 8. 国际化与输入

使用 Fluent 组织可见文案、提示、菜单与无障碍名称。文件名和 URI 不翻译。数量使用 Fluent 复数规则，日期与数字遵循区域设置。为中文、英文和较长翻译留出空间，不把按钮宽度锁死在某一种语言上。

所有主要功能可用键盘到达；焦点返回到触发控件，菜单关闭后不丢失文件选择。高 DPI、字体放大、减少动效和高对比设置均属于公共组件的责任。

## 9. 第一款应用如何验证这套语言

文件浏览器的 [概念设计](../apps/files/concept.md) 是第一次应用，而不是主题系统的宿主。后续应用复用语义 token、图标词汇、组件与外观配置；不依赖文件浏览器模块，也不复制它的样式表。
