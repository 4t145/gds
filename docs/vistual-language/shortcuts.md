# GDS 快捷键与键帽 · 概念规范 0.3

本文是整个套件的**默认绑定、显示方式与焦点规则**的集中定义，并纳入原生入口修订；文件浏览器和后续应用引用同一规则，不各自复制一份快捷键表。设置通过主页面左上菜单或 `Ctrl+,` 进入；设置、最近、收藏等次级页以同一左上位置的 ArrowLeft 返回文件浏览，没有底部设置按钮或右上返回 X。公共视觉基线见 [视觉语言](README.md)，即时应用规则见 [设置中心](../settings/README.md)。

以下链接保留历史示意，不作为当前入口 / 保存方式或原生交互验收的证据：[历史交互原型](../apps/files/concept.html) · [按钮悬停示意](../apps/files/concept-shortcuts.png) · [快捷键页示意](../apps/files/concept-keybindings.png)

## 1. 同一语义，同一绑定

相似动作在不同应用、同一应用的不同位置采用相同默认绑定。动作的作用对象由明确的 scope 与当前焦点决定，不由鼠标悬停位置偷偷改变。

### 五个核心动作

| 语义 action ID（概念） | 动作 | 默认键帽 | 作用域 |
| --- | --- | --- | --- |
| `settings.open` | 打开 / 聚焦完整设置中心 | <kbd>Ctrl</kbd> <kbd>,</kbd> | 显式窗口级 |
| `tab.new` | 新建页签 | <kbd>Ctrl</kbd> <kbd>N</kbd> | 当前文件工作区，或聚焦的终端页签栏 |
| `tab.close` | 关闭当前页签 | <kbd>Ctrl</kbd> <kbd>W</kbd> | 当前文件工作区，或聚焦的终端页签栏；保留关闭确认 |
| `panel.terminal` | 显示 / 收起终端 | <kbd>Ctrl</kbd> <kbd>`</kbd> | 显式窗口级，作用于整个终端 dock |
| `panel.sidebar` | 展开 / 折叠侧栏 | <kbd>Ctrl</kbd> <kbd>B</kbd> | 具有侧栏的当前应用界面；不覆盖终端文本输入 |

本轮新建页签按 **Ctrl+N** 定义，替换此前的新建绑定，不保留另一组新建页签别名。`tab.new` 和 `tab.close` 在不同页签栏复用语义，但必须解析到相应的文件或终端目标。

### 对话框动作

所有模态对话框共用同一组键帽。它们只在对话框的 `Dialog` 上下文中注册，文件工作区、设置页和终端都不响应。

| 动作 | 默认键帽 | 作用域 |
| --- | --- | --- |
| `dialog.confirm` | <kbd>Alt</kbd> <kbd>A</kbd>；同时保留 <kbd>Enter</kbd> | 打开的对话框；执行主操作 |
| `dialog.cancel` | <kbd>Alt</kbd> <kbd>C</kbd>；同时保留 <kbd>Esc</kbd> | 打开的对话框；执行取消或关闭 |

主操作按钮的图标与短文案由调用方提供，取消按钮固定使用叉号与普通款；危险确认只把主操作换成危险色。对话框底部按钮的悬停提示沿用同一 Badge 显示实际绑定，不另写快捷键字符串。

`Alt` 组合先由对话框消费，不写入输入框，也不触发对话框后面的工作区快捷键。主操作失败（如表单校验不通过）时对话框保持打开；取消继续走对话框原有的取消回调，包括结束进行中的拖拽，不绕过它。

### Ctrl+Tab 页签前缀

按住 `Ctrl+Tab` 后再按目标键直接跳转；若没有目标键，松开 Tab 时才循环到下一页签，`Ctrl+Shift+Tab` 则反向。目标已选择后，松开 Tab 不再额外切一次。失去窗口激活或模态接管时取消未完成的前缀。

| 目标键 | 目标 |
| --- | --- |
| `H` | 主文件夹（Home） |
| `R` | 最近 |
| `D` | 收藏 |
| `N` | 网络 |
| `B` | 回收站 |
| `1`–`9` | 按侧栏顺序的第 1–9 个普通文件页签 |

位置条目是固定特殊页签，不挤入普通页签编号；没有对应编号时不跳转。Home 独立于普通页签列表，普通页签可以全部关闭，关完自动显示 Home。`Esc` 用于局部取消，不退出这些特殊页签。展开和收起侧栏共用“本行悬停或按住 Ctrl 时显示关闭按钮”的规则，特殊页签不提供关闭按钮；收起时用右上角小 X，悬停提示名称及完整路径。

### 既有交互的建议默认

下表保留已设计的非核心动作，集中在此维护；它是实际 GPUI 应用的设计目标，**不代表 HTML 原型已经实现完整编辑或文件快捷键**。无相应能力的应用不注册该动作。

| 动作 / 上下文 | 建议默认键帽 |
| --- | --- |
| 打开 / 关闭左上主菜单 | <kbd>Alt</kbd> <kbd>M</kbd>，兼容 <kbd>F10</kbd>；与左上菜单按钮同一动作、同一份菜单 |
| 编辑路径 | <kbd>Ctrl</kbd> <kbd>L</kbd> |
| 恢复已关闭的文件页签 | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>T</kbd> |
| 选中目录在新文件页签打开 | <kbd>Ctrl</kbd> <kbd>Enter</kbd> |
| 下一个 / 上一个同组页签 | <kbd>Ctrl</kbd> <kbd>Tab</kbd> / <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Tab</kbd> |
| 后退 / 前进 / 上级 | <kbd>Alt</kbd> <kbd>←</kbd> / <kbd>Alt</kbd> <kbd>→</kbd> / <kbd>Alt</kbd> <kbd>↑</kbd> |
| 聚焦常驻筛选 / 显示隐藏文件 | <kbd>Ctrl</kbd> <kbd>F</kbd> / <kbd>Ctrl</kbd> <kbd>H</kbd> |
| 文件焦点前后 / 首末项 | <kbd>↑</kbd> / <kbd>↓</kbd> / <kbd>Home</kbd> / <kbd>End</kbd>，配合 <kbd>Shift</kbd> 扩选 |
| 全选可见文件 | <kbd>Ctrl</kbd> <kbd>A</kbd>；文本输入框保持文本全选 |
| 收藏 / 取消收藏当前文件夹 | <kbd>Ctrl</kbd> <kbd>D</kbd>；同一动作切换两种状态，未收藏时添加、已收藏时取消；星标按钮相同 |
| 配置表格列 | <kbd>Alt</kbd> <kbd>V</kbd>，与文件内容标题栏的列配置按钮同一动作 |
| 重命名 / 刷新 / 属性 | <kbd>F2</kbd> / <kbd>Ctrl</kbd> <kbd>R</kbd>（兼容 <kbd>F5</kbd>） / <kbd>Alt</kbd> <kbd>Enter</kbd> |
| 打开 / 收起右侧详情栏 | <kbd>Ctrl</kbd> <kbd>P</kbd>；只作用于文件工作区，不切换设置或集合页。<kbd>Ctrl</kbd> <kbd>R</kbd> 现在用于刷新，不再打开详情 |
| 剪切 / 复制 / 粘贴：文件视图 | <kbd>Ctrl</kbd> <kbd>X</kbd> / <kbd>Ctrl</kbd> <kbd>C</kbd> / <kbd>Ctrl</kbd> <kbd>V</kbd>；粘贴到当前目录 |
| 复制选中文件的路径 | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>C</kbd> |
| 取消进行中的拖拽 | <kbd>Esc</kbd>；取消拖拽不清空文件选择 |
| 移至回收站 | <kbd>Delete</kbd>；直接移动，不确认 |
| 永久删除 | <kbd>Shift</kbd> <kbd>Delete</kbd>；明确提示不可恢复并要求确认 |
| 回收站恢复 / 永久删除选中 / 清空 | <kbd>Alt</kbd> <kbd>R</kbd> / <kbd>Alt</kbd> <kbd>D</kbd> / <kbd>Alt</kbd> <kbd>Shift</kbd> <kbd>D</kbd>；仅回收站有效，危险动作仍先确认 |
| 清空最近记录 | <kbd>Alt</kbd> <kbd>C</kbd>；仅最近页有效，Broom 图标，不清收藏或固定页签 |
| 复制 / 粘贴：终端 | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>C</kbd> / <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>V</kbd> |
| 从终端返回文件视图 | <kbd>F6</kbd>，可重映射 |
| 终端跳转到当前文件夹 | 未绑定；先保留明确的工具栏动作 |

<kbd>Alt</kbd> <kbd>M</kbd>（兼容 <kbd>F10</kbd>）与左上菜单按钮是同一个动作、同一份菜单：鼠标与按键只驱动一个打开状态，不会叠出第二份菜单；按住 <kbd>Alt</kbd> 时按钮右上角角标显示 `M`，tooltip、菜单右列与设置页显示主键 <kbd>Alt</kbd> <kbd>M</kbd> 而不是兼容键 <kbd>F10</kbd>，<kbd>F10</kbd> 不含修饰键，因此不进入 Ctrl / Alt 任一组提示。菜单在普通文件页和固定特殊页签中共用，只保留“设置”和“关于”；设置中心自身仍用左上返回入口。路径编辑或模态对话框期间不打开背景主菜单；筛选词随输入即时保存，不因菜单开合丢失。`Esc` 关闭菜单并把焦点交回工作区，但不退出其所在的特殊页签。

<kbd>F2</kbd> 重命名使用独立输入对话框：初值选中完整文件名，输入框或对话框聚焦时文件快捷键不触发；<kbd>Enter</kbd> 提交，<kbd>Esc</kbd> 取消，同名目标不覆盖。只允许单选，多选不伪造批量重命名。

<kbd>Alt</kbd> <kbd>V</kbd> 与标题栏列配置按钮共用同一动作，列配置对话框已打开时不会再打开第二个；<kbd>Ctrl</kbd> <kbd>D</kbd> 只在文件工作区、当前文件夹已加载且没有进行中的导航时生效，设置、集合、路径 / 筛选编辑框与对话框保持既有焦点保护。星标与 <kbd>Ctrl</kbd> <kbd>D</kbd> 是同一动作：未收藏时显示“收藏当前位置”、已收藏时显示“取消收藏”，两种状态都附 <kbd>Ctrl</kbd> <kbd>D</kbd>，快捷键设置里写“收藏 / 取消收藏”而不是只写收藏。

## 2. 公共 ShortcutBadge

每个物理按键使用一枚紧凑、独立的 `kbd` 键帽。组合键是一组键帽，不是包含整段 `Ctrl+N` 的长胶囊。

- 单枚键帽高 **22 px**、最小宽 **22 px**、圆角 **4 px**；键帽之间间距 **4 px**。长键名允许加宽，不能把 `Shift`、`Enter` 等缩成含糊缩写。
- 整组按键不拆行。空间不足时扩展提示或菜单布局，而不是把一个组合键折到两行。
- 修饰键排序固定为 **Ctrl → Alt → Shift → 主键**。Linux 使用 `Ctrl`、`Alt`、`Shift`，不混用 macOS 的 ⌘、⌥ 等符号。
- 键帽之间只有间距，**不插入裸 `+` 号或斜杠分隔符**。如果真正绑定的是加号键，它本身占一枚 <kbd>+</kbd> 键帽；不能把分隔符误读成额外按键。本文表格中的 `/` 只用于区分多个独立动作，不属于组合键显示。
- 使用公共语义色：例如 `surface.control` 背景、`text.secondary` 前景和 `border.subtle` 轻描边。保持可读性，但不抢动作、选中或焦点的强调色，不使用醒目的彩色按键装饰。
- 按钮 tooltip、菜单右侧快捷键列和“设置 → 快捷键”都调用**同一个 Badge**，共用尺寸、键名格式和间距。菜单右列 / 设置绑定列统一对齐，不逐项手写偏移；对话框底部按钮的悬停提示也用同一 Badge 显示 `Alt+A` / `Alt+C`。

## 3. 按钮 tooltip

统一结构为**左侧短动作名，右侧组合键 Badge**。必要的原因或补充说明放在次行，不把工具提示写成长段帮助文档。

- 鼠标稳定悬停 **400 ms** 后显示；键盘聚焦时及时显示，不要求用户再等待悬停计时。
- 鼠标离开触发区、焦点离开、点击或 `Esc` 时关闭；点击后取消待触发计时，不能在动作已经执行后迟到弹出。
- tooltip 不透明，主题切换只改变其语义配色。底部控件优先向上显示，靠边时在应用框架范围内避让边缘；不得覆盖触发按钮或挡住用户继续点击它，也不同时显示原生 `title` 提示。
- tooltip 不抢焦点，也不包含必须进入才能完成动作的交互。短动作名使用 Fluent 文案；键帽由绑定数据生成。
- 禁用动作说明必要的禁用原因；tooltip 可解释状态，但不能使禁用控件重新可执行。
- 未绑定动作只显示动作名和必要说明，不虚构默认键。设置绑定列可明确显示“未绑定”，不画一枚假的按键。
- **显示的绑定必须与按钮的实际目标一致。** 例如关闭非活动文件标签的按钮不能显示 <kbd>Ctrl</kbd> <kbd>W</kbd>，让人误以为该快捷键会关闭鼠标下的标签。聚焦终端页签栏时，文件标签按钮也不能借用当前终端 scope 的绑定。无法确认目标一致时省略 Badge，而不是改变键盘分发目标。

动态动作名也要对应状态，例如“显示终端 / 收起终端”“展开侧栏 / 折叠侧栏”；它们仍引用同一个 toggle 动作的有效绑定。

### 按住修饰键的功能提示

按住 <kbd>Ctrl</kbd> 或 <kbd>Alt</kbd> 时，当前界面里**确实已有绑定**的控件显示紧凑单片标签，例如 `R`、`Shift+Tab`、`A`，松开立即消失，不要求先悬停。两个修饰键各成一组：按 <kbd>Ctrl</kbd> 只显示绑定带 Ctrl 的控件，按 <kbd>Alt</kbd> 只显示绑定带 Alt 的控件，没有对应修饰键的 <kbd>F2</kbd> / <kbd>Delete</kbd> / <kbd>F5</kbd> 不因按住修饰键而出现。标签只省略已按住的修饰键前缀，保留 <kbd>Shift</kbd> 和实际按键：`Ctrl+R` 显示 `R`，`Ctrl+Shift+Tab` 显示 `Shift+Tab`，`Alt+A` 显示 `A`。键名仍来自 ShortcutBadge 的同一份键名来源，不另写映射；tooltip、菜单和设置绑定列继续显示完整组合，如 `Ctrl+R`、`Alt+A`。Ctrl+Alt（以及 AltGr 上报的这个组合）不属于任何一组，此时不显示标签，也不改变按键分发。

- 标签锚点按控件类型分开：图标按钮的标签是**右上角角标**，锚点在该按钮内部角落；NavItem 图文行放在**本行尾部**，折叠成图标时改为右上角角标；文件页签行把页签切换标签放在关闭控件之前的行尾空间，与关闭按钮的 `W` 角标各占一处；对话框的图标 + 文字按钮在文字之后预留一条很小的固定尾槽，标签放在末尾而不是按钮下缘，不压按钮文字，也不覆盖危险确认中的数量。预留空间恒定，按住 Ctrl / Alt 时整排按钮不跳动。
- **Ctrl 预览层：**普通 Ctrl 操作照常显示；可循环直达的相邻文件页签显示 `Tab` / `Shift+Tab`，不重复显示数字路径。其余可编号页签显示 `Tab+1` 等，位置行显示 `Tab+H` / `Tab+R` / `Tab+D` / `Tab+N` / `Tab+B`。这些是先进入页签前缀再选目标的真实按键路径，不表示 Ctrl+H 能直接到 Home。
- **Ctrl+Tab 导航层：**前缀激活后只显示目标数字 `1`–`9` 与位置字母 `H/R/D/N/B`，隐藏普通操作的 `W/N/R…` 和循环提示 `Tab/Shift+Tab`。松开 Tab 返回 Ctrl 预览层，松开 Ctrl 或失焦清除全部提示。收起侧栏的导航标签单独定位，不因右上关闭 X 可见而消失。
- 设置页的上一项 / 下一项仍在相邻导航行显示；模态只显示自身可用操作。页签顺序、首尾循环与按键分发共用同一份目标数据；两个文件页签时，Ctrl 预览层的两个循环提示可并排落在同一目标行，只有一个时不显示无效循环。
- 标签按**当前焦点作用域**解析绑定：对话框打开时只显示该对话框自己的 `Alt+A` / `Alt+C`，不把后面的工作区快捷键当成可用提示；禁用控件、当前作用域下解析不到绑定的控件、以及绑定不含所按修饰键的控件都不显示。
- 标签紧贴对应控件的角落 / 行尾，必要时略作偏移避开相邻标签；窗口边缘允许贴边调整，但不把标签挪到远处。标签本身不拦截点击、不抢焦点、不改变控件尺寸：对话框按钮的尾槽在按钮内固定预留，其它控件的标签是绝对定位的浮层；滚动、字体缩放和窗口高度变化后跟随控件，模态内标签位于遮罩之上。
- 松开修饰键或失去窗口激活（包括在窗口外松开）即清除，不残留。输入框与下拉框保持原有焦点和编辑行为，`Ctrl` / `Alt` 组合照常分发，不把字母写入输入、不覆盖 `Enter` / `Esc`、文件选择和拖拽取消。

## 4. 焦点与 scope 契约

| 当前焦点 / 场景 | 分发约定 |
| --- | --- |
| 文件工作区或文件页签栏 | `tab.new` 新建文件页签；`tab.close` 关闭当前活动文件页签，不取鼠标悬停目标。含终端会话时仍经过结束会话确认，取消则保留全部上下文。`panel.details`（Ctrl+P）只在文件工作区切换详情栏，设置与集合页不响应。 |
| 终端左侧页签栏 | 同一 `tab.new` 创建终端页签；`tab.close` 结束当前活动终端页签，保留现有确认。不会误关外层文件标签。 |
| 终端文本输入区 | **Ctrl+W / N / B / L / C 保留给 shell / 前台程序**，文件应用不截获；不能把“终端页签栏聚焦”与“PTY 输入聚焦”混为一谈。 |
| 路径、搜索等编辑框 | 输入组件原生编辑快捷键不改；不得为了文件动作覆盖其编辑行为。未被输入组件消费的动作才按有效 scope 处理。 |
| 设置中心 | `Ctrl+Tab` / `Ctrl+Shift+Tab` 按侧栏顺序双向循环设置页，首尾相接；不切换背后的文件标签。设置不是可关闭的文件页签，Ctrl+N / W 不在背后新建或关闭文件标签。使用 `Esc` 或左上 ArrowLeft 返回文件浏览；若子控件正在编辑 / 有临时浮层，先处理局部取消。偏好已即时应用，返回不是提交或撤销已生效修改。 |
| 模态对话框 | `Alt+A` / `Enter` 执行主操作，`Alt+C` / `Esc` 取消；这些键只在对话框层匹配，输入框聚焦时也不写入字符，不落到后面的工作区。 |

**显式窗口级例外只有本轮确认的两项：Ctrl+, 与 Ctrl+反引号。** 它们在终端文本或编辑框聚焦时仍由窗口处理：前者到达完整设置中心，后者切换整个终端 dock，包括左侧会话页签。设置中也由窗口处理这两项动作，不把它们误路由成文件标签操作。

收起仍持有焦点的区域后，把焦点移回仍可见的触发控件或文件工作区，不能把焦点留在隐藏终端里。普通页面不会因为鼠标悬停某个按钮而切换键盘 scope。

全屏 TUI 与应用键位冲突在实际终端接入时验证，后续通过显式重映射解决；本轮不假装已有真实 shell、PTY 或完整按键编辑器。

## 5. 数据只有一个来源

公共动作记录提供 **语义 action ID + 有效 binding + scope**，供以下四处共同消费：

```text
公共动作与有效绑定
  ├─ 按键分发：解析焦点、作用域、目标与启用状态
  ├─ 按钮 tooltip：动作名 + 对应目标的绑定 Badge
  ├─ 菜单：动作项 + 统一右侧快捷键列
  └─ 设置 → 快捷键：动作、有效绑定、作用域
```

控件不能各自硬编码展示字符串。未来用户重映射后，按键分发、tooltip、菜单和设置页同时读到新绑定；不能只改提示而仍执行旧键，也不能保留未明确设计的隐藏别名。启用状态与目标解析属于动作消费过程，不由 Badge 自己猜测。

对话框的 `Alt+A` / `Alt+C` 也来自同一份绑定数据：启动时只在 `Dialog` 作用域注册一次，按钮、设置页和 tooltip 都读取它，不按对话框各写一份。

首期使用明确的动作集合和绑定数据即可，不构建插件系统、通用配置语言或完整重映射编辑器。“设置 → 快捷键”仍是统一设置中心内的一页，**主页面菜单与 Ctrl+, 始终进入完整设置中心，不改成快捷键专用入口**。

## 6. 无障碍与标点键

- 控件无障碍名称保持短动作名，如“设置”“新建文件页签”“收起终端”；不要把说明、整串快捷键和状态全塞进名称。
- HTML 原型在具有对应有效绑定的控件上使用 `aria-keyshortcuts`；其语法仍按属性标准写，例如 `Control+n`、`Control+w`、`Control+,`。属性中的 `+` 是组合语法，与屏幕上不加裸分隔符的键帽规则不同。
- 逗号显示为 <kbd>,</kbd>，可访问读法为“逗号”；反引号显示为 <kbd>`</kbd>，读作“反引号”，不与单引号混淆。修饰键与主键按组合语义表达，避免屏幕阅读器只念出无法辨认的标点。
- 独立展示的 Badge 提供清楚的组合读法，例如“Ctrl 与逗号”。若触发控件已通过 `aria-keyshortcuts` 暴露绑定，应避免键帽内部碎片被重复朗读。tooltip 的必要说明可与触发控件关联，不替代其短名称。
- 无绑定或当前目标不匹配的按钮，不填写虚假的 `aria-keyshortcuts`。原生 GPUI 实现采用对应的可访问语义，不把 HTML 属性当成原生平台已经支持的证据。

## 7. 0.3 原型范围与验收

本轮原型示范五个核心动作、统一 Badge 与 hover 布局，以及文件标签关闭确认。它仍只使用示例状态，不操作真实文件、配置或 PTY；完整普通编辑快捷键、所有次要动作和完整重映射编辑器不在本轮实现承诺内。

宿主浏览器可能截获 **Ctrl+N / Ctrl+W** 等保留键，即便页面声明了绑定也不保证收到按键。原型可通过对应按钮验证交互，但这不等于通过真实 GPUI 键盘验收；实际应用需再验证按键分发、布局 / 输入法和终端焦点。

验收重点：

1. 同一语义在各应用、按钮、菜单和设置中显示相同的有效绑定，不残留旧的新建页签别名。
2. 五个核心动作均用独立键帽；逗号、反引号、长键名、多修饰键和真正的加号键不会歧义或拆行。
3. tooltip 的延时、关闭、键盘聚焦、底部 / 边缘避让和禁用原因一致，不覆盖触发按钮、不抢焦点。
4. 文件页签栏、终端页签栏、终端文本区、编辑框与设置中心的目标 / 焦点契约分别成立；关闭行为不绕过确认。
5. 有效绑定改变时四个消费者同步；未绑定或非活动目标按钮不伪报快捷键。
